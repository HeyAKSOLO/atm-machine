# ATM System (C++)

# A console based ATM simulation built using c++ and OOP

### Feature
- create account (savings/current)
- login
- see account details
- deposit
- withdraw
- logout
- na

### Concepts used
- Conditionals
- loops
- functions
- Pointers
- vectors
- OOP

### Version control
- Git
- Github

### Current Status
- working in progress

## How to use
### Main Menu
1. Create Account
2. Login
3. Exit

### User Menu
> After Login:
1. Deposit Money
2. Withdraw Money
3. Display Account Details
4. Logout
